# МИН МОЛ: учет мероприятий и отчетность

Локальная настольная программа для ведения целевых показателей, учета мероприятий, автоматического расчета охватов и формирования отчетных форм.

## Запуск

Откройте файл `Запустить программу.bat` двойным щелчком.

Если на другом компьютере отсутствуют библиотеки, один раз выполните:

```powershell
python -m pip install -r requirements.txt
```

Затем запустите программу повторно.

## Порядок работы

1. На вкладке `Обзор` проверьте организацию и отчетный год.
2. На вкладке `Целевые показатели` задайте для каждого направления план нарастающим итогом по месяцам.
3. На вкладке `Мероприятия` вносите дату, время, место, название, описание, количество участников и ссылку.
4. Карточку можно сохранить как черновик: сначала заполнить дату, время, место и название, а после проведения дополнить описание, количество и ссылку.
5. Оставьте включенным автоматическое определение показателей или отключите его и выберите показатели вручную.
6. На вкладке `Отчеты` выберите отчетный месяц, откройте предпросмотр и нажмите `Выгрузить все 3 отчета`.

Текст можно копировать и вставлять стандартными сочетаниями клавиш или через меню правой кнопки мыши. Выбранную строку таблицы также можно скопировать.

## Отчетный период

Отчетный месяц начинается 25-го числа предыдущего календарного месяца и заканчивается 24-го числа выбранного месяца. Например, отчет за февраль включает мероприятия с 25 января по 24 февраля. Дата мероприятия не изменяется, программа только относит его к нужному отчету.

## Автоматические расчеты

- `Разница планов` = план нарастающим текущего месяца минус план предыдущего месяца.
- `Факт за месяц` = сумма участников всех мероприятий месяца, относящихся к показателю.
- `Факт нарастающим` = сумма фактического охвата с января по текущий месяц.
- `Нужно с остатком` = разница планов текущего месяца плюс остаток предыдущего месяца.
- `Необходимо - сделано` = нужно с остатком минус факт текущего месяца.

Отрицательный остаток означает опережение плана и переносится в следующий месяц согласно логике исходной таблицы.

## Файлы

- Данные автоматически сохраняются в `данные/данные.json`.
- По умолчанию отчеты сохраняются в папку `отчеты`.
- `Приложение 1` формируется в DOCX с накопительными значениями пяти показателей.
- `Приложение 2` формируется в DOCX с мероприятиями по разделам.
- Сводные данные формируются в XLSX с листом расчетов и отдельными листами по месяцам.

Перед официальной отправкой рекомендуется проверить автоматически назначенные целевые показатели: формулировки конкретного мероприятия могут требовать экспертного решения ответственного сотрудника.

## Настройка форм

На вкладке `Настройка форм` можно:

- добавлять и удалять целевые показатели;
- менять код, номер строки, рабочее и официальное название показателя;
- редактировать заголовки разделов приложения 2;
- задавать ключевые слова автоматической классификации;
- менять заголовки и названия столбцов приложений 1 и 2;
- переименовывать стандартные поля карточки мероприятия;
- добавлять собственные поля в карточку и сводную книгу Excel.

## Поиск

На вкладке `Мероприятия` поиск работает по полной дате или части названия. Найденная карточка выделяется в таблице и открывается справа, под таблицей показывается краткая информация.

## Пресс-релизы

На вкладке `Пресс-релизы` выберите мероприятие. Программа покажет его краткое описание. Кнопка `Сгенерировать пресс-релиз` передает данные карточки модели DeepSeek, после чего ответ появляется в поле `Текст пресс-релиза`. Готовый текст можно отредактировать и сохранить кнопкой `Выгрузить в Word`.

По умолчанию указана модель `deepseek-flash`. URL и модель можно изменить под используемого провайдера. При включенном флажке запоминания API-ключ шифруется Windows DPAPI для текущей учетной записи и хранится в `данные/api_key.bin`; открытого ключа в исходном коде и `данные.json` нет. После первого ввода ключ подставляется автоматически. Его можно удалить кнопкой `Удалить сохраненный ключ`. Вместо поля ключ также можно передать через переменную среды `DEEPSEEK_API_KEY`.

При запуске программа выбирает последний отчетный месяц, в котором есть мероприятия. Если для приложения 2 выбран пустой месяц, программа предложит сформировать документ за последний заполненный месяц вместо создания пустого файла.
