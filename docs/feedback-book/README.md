# Книга обратной связи

Готовая статическая веб-программа в папке `docs/feedback-book`.

## Возможности

- выбор учреждения культуры ЛНР из выпадающего списка;
- анонимное обращение: жалоба, предложение, благодарность или вопрос;
- тема, дата события и сообщение от 15 до 1000 символов;
- открытая книга с фильтром по учреждению;
- режим увеличенного текста для слабовидящих;
- вход для администратора и просмотр/удаление обращений;
- сохранение демонстрационных данных в `localStorage` браузера.

## Запуск

Откройте `index.html` в браузере. Для размещения на Render, GitHub Pages или другом статическом хостинге загрузите содержимое этой папки.

Текущая версия работает без сервера: обращения видны только в том браузере, где они созданы. Для единой общей книги с реальным администратором потребуется подключить серверный API и базу данных.

## Демонстрационный вход администратора

- логин: `admin`
- пароль: `admin123`

Перед публикацией необходимо заменить демонстрационную проверку на серверную аутентификацию, хеширование пароля и роли пользователей.

Перечень учреждений составлен по открытым публичным упоминаниям государственных и муниципальных учреждений культуры ЛНР. Перед официальным запуском его необходимо сверить с актуальным реестром Министерства культуры ЛНР.
