# МИН МОЛ

Локальная программа для учета мероприятий молодежной политики, контроля целевых показателей и подготовки отчетности.

## Возможности

- ведение карточек мероприятий;
- расчет фактических охватов по целевым показателям;
- отчетный период с 25-го числа предыдущего месяца по 24-е число выбранного месяца;
- подготовка приложений 1 и 2 в Word;
- экспорт сводных данных в Excel;
- генерация пресс-релизов через DeepSeek;
- выгрузка пресс-релизов в Word;
- защищенное хранение API-ключа средствами Windows DPAPI.

## Запуск

1. Установите Python 3.
2. Установите зависимости командой `pip install -r requirements.txt`.
3. Запустите `Запустить программу.bat`.

Рабочие данные, API-ключи и сформированные отчеты не публикуются в репозитории.
